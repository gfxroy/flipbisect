How it works

Three steps from "it's random" to the exact cause.

01

Replay

It sends the same temperature-0 request solo, after a cache flush, and inside bursts of 2, 4 and 8 mixed-length neighbours. It works with any OpenAI-compatible server.

02

Find the split

It finds the first token where the answers differ. It reads the top logprobs there, so a harmless near-tie is labelled differently from a real divergence.

03

Bisect the settings

It relaunches the server with different settings and uses delta debugging to narrow them down to the smallest change that still breaks determinism.

Honest limits

What this does and doesn't prove.

Zero flips isn't proof

Rare flips (about 1–2%) showed up in configs that looked stable. Use enough repeats.

One model, one box

It's a demo on CPU, not a benchmark. The vLLM and SGLang backends are written but not yet run on a GPU.

First split only

It finds where and which setting, not which layer or kernel.
